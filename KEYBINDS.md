# Keybinds

Snapshot of every mapping in this config. Generated by dumping live keymaps from a
running instance (`nvim_get_keymap` across all modes) rather than by reading source,
so lazy-loaded and plugin-registered binds are included. Buffer-local maps — LSP and
the Outline window — are listed separately, since they only exist once attached.

`<leader>` is <kbd>Space</kbd>. Neovim's own built-in defaults (`]b`, `[q`, `gcc`
fallbacks and friends) are omitted except where this config overrides them.

For an interactive view: `<leader>ch` opens the NvChad cheatsheet, `<leader>wK`
lists every keymap via which-key.

## Markdown and reading

Rendering is handled by markview.nvim automatically; these are the manual controls.

| Key | Mode | Action |
| --- | --- | --- |
| `<leader>z` | n | Toggle Zen Mode — centred 90-column reading view |
| `<leader>mp` | n | Toggle markdown preview in browser |
| `<leader>oo` | n | Toggle Outline sidebar |
| `<leader>of` | n | Toggle focus between document and Outline |

Useful built-ins for long documents, since treesitter folding is configured with
`foldlevel=99` (everything starts open):

| Key | Action |
| --- | --- |
| `zM` | Collapse everything to headings — acts as a table of contents |
| `zR` | Expand everything again |
| `za` | Toggle the fold under the cursor |
| `zc` / `zo` | Close / open one fold |

Commands worth knowing: `:Markview toggle` A/Bs raw against rendered in place, and
`:Twilight` gives the dim-inactive-paragraph effect on demand (it is deliberately
disabled inside Zen Mode).

Markdown buffers also drop their gutter and enable `breakindent`, so wrapped lines
stay aligned with their block. That is automatic — no keybind.

## Outline

Global toggles are in [Markdown and reading](#markdown-and-reading). These are
buffer-local, active only while the cursor is inside the Outline sidebar.

| Key | Action |
| --- | --- |
| `o` | Peek — jump the document but keep the cursor in the outline |
| `<CR>` | Jump to symbol, outline stays open |
| `<S-CR>` | Jump to symbol and close the outline |
| `K` | Toggle preview popup |
| `<C-Space>` | Hover symbol |
| `<C-g>` | Restore original cursor location |
| `h` / `l` | Fold / unfold section |
| `<Tab>` / `<S-Tab>` | Toggle fold under cursor / all folds |
| `W` / `E` | Fold all / unfold all |
| `R` | Reset folds |
| `<C-j>` / `<C-k>` | Move down / up **and** jump |
| `r` | Rename symbol |
| `a` | Code actions |
| `?` | Show help |
| `<Esc>` or `q` | Close outline |

`<C-j>` / `<C-k>` are overridden here, shadowing the global window-focus binds. Use
`<C-h>` to get back to the document — the outline is a full-height right split, so
there is nothing above or below it anyway.

## Known conflicts

Found while generating this file by comparing what the config *defines* against what
actually resolves at runtime.

### `<C-A-h>` and `<C-A-l>` never resize windows

`mappings.lua:63-64` maps them to window width resize, then `mappings.lua:135` and
`mappings.lua:143` remap the same keys to terminal toggles. Later definition wins, so
the resize binds are unreachable:

| Key | Intended (line 63/64) | Actually does |
| --- | --- | --- |
| `<C-A-h>` | Increase width by 5 | New horizontal terminal |
| `<C-A-l>` | Decrease width by 5 | Horizontal terminal in buffer's directory |

Height resize (`<C-A-k>` / `<C-A-j>`) is unaffected and works. To get width resize
back, pick different keys for one of the two pairs.

Both terminal maps also carry the identical description
`"Term toggle horizontal split in buffer location"`, though `mappings.lua:143`
creates a *new* terminal rather than toggling one — a copy-paste slip in the `desc`
that makes which-key show two identical entries.

### `cc` shadows Vim's change-line

`ccc.nvim` maps `cc` globally in normal mode to `CccConvert`, so the built-in
"change line" is no longer available on `cc`. Use `S` or `0C` instead, or rebind the
ccc mapping in `lua/plugins/spec/ccc.lua:7`.

### Mode-dependent overloads

Not bugs, but worth knowing — these do different things depending on mode:

| Key | Normal | Visual |
| --- | --- | --- |
| `<leader>cs` | Clear statusline | Code snapshot to `~/Pictures` |
| `<leader>cc` | Blankline jump to context | Code snapshot to clipboard |
